# TERM PROJECT — BLG 632E: Next Generation Wireless Networks

## 1. Project Objective

Each student will conduct an individual research project within the scope of the course, focusing on **one** of the following domains:

- Self-Organizing Networks (SON)
- Software Defined Networking (SDN)
- Knowledge Defined Networks (KDN)
- Digital Twin for Networks (DTs)
- Aeronautical Ad-Hoc Networks (AANETs)

### The project must:

1. Identify a clearly defined technical challenge in the selected domain.  
2. Analyze the existing literature to demonstrate a research gap.  
3. Propose an original technical contribution addressing the challenge.  
4. Validate the proposal through analytical, theoretical, or experimental evaluation.  
5. Present the work in IEEE conference paper format (5–6 pages).  
6. Deliver an academic presentation.  

---

## 2. Expected Research Depth

### 2.1 Problem Formulation

- Clearly define the technical problem.  
- Provide a formal system model.  
- Include mathematical formulation where applicable.  
- Explicitly state assumptions and constraints.  
- Define objective function(s) and performance metric(s).  

---

### 2.2 Literature Gap Analysis

- Review at least **10 recent high-quality publications** (preferably from the last 5 years).  
- Identify limitations of existing approaches.  
- Explain why current solutions are insufficient.  
- Specify under which conditions they fail.  
- Discuss unresolved performance trade-offs.  

---

### 2.3 Original Contribution

Your contribution may include one or more of the following:

- A new network architecture  
- A new algorithm  
- A new optimization framework  
- A new performance metric  
- A new control mechanism  
- A novel integration of existing paradigms  

---

### 2.4 Evaluation (At Least One Required)

- Simulation (e.g., Mininet, NS-3, OMNeT++, MATLAB, Python-based simulation)  
- Analytical performance modeling  
- Theoretical proof or stability analysis  
- Proof-of-concept implementation  
- Complexity analysis with scalability discussion  

---

## 3. Report Requirements: IEEE Paper Format

The final submission must follow the IEEE conference format (two-column template, 5–6 pages).

### Required Sections:

- Abstract  
- Introduction  
- Related Work  
- System Model  
- Proposed Method  
- Performance Evaluation  
- Conclusion  

---

## 4. Presentation Requirements

- **Duration:** 20 minutes  
- **Content:**
  - Problem definition & research gap  
  - Proposed method  
  - Results & evaluation  
  - Q&A
